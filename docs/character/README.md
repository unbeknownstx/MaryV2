# Mary Character Sources

Mary's authored character source hierarchy is separate from lived AI continuity.

- `character_sources/drafts/` — raw work in progress. Not automatically loaded.
- `character_sources/active/` — creator-approved source material Mary may retrieve at runtime.
- `mary.character.sourcebook` — read-only bridge into TurnMind.
- `mary.character.evaluation` — evaluation examples/anti-examples; never durable memory.

Keep the raw authored Bible/corpus intact. Derive machine-readable rules, training/evaluation examples and performance packets from it rather than replacing it.
