# CharacterSourcebook Beta — Provenance Notes

## Authority order used for this pass

1. Creator-authored filled Mary workbook material.
2. Existing Alpha CharacterSourcebook and its established invariants.
3. Fictional Mary behavior from Unbeknownst as `[FC]` reference only, never AI autobiography.
4. Explicit creator feedback about live AI Mary behavior.
5. UI/screenshots as product evidence, not character canon.
6. Generated visual references as visual studies only.

## Promotion rule

A detail entered the active beta only when it was directly authored or was a conservative synthesis of directly authored answers. Delegated blanks and “make it up” requests remain open. That prevents assistant-completed trivia from silently hardening into canon.

## Why only 23 records were added

The workbook contains much more material, but Alpha already represents major invariants such as autonomy, emotional intelligence, competence plus imperfection, rain/lavender, wardrobe DNA, cooking contradiction, work lateness, attraction shyness, provider/identity boundaries and anti-catchphrase rules. Repeating those facts would distort retrieval by frequency.

This beta therefore adds **18 lived-world records + 5 interaction-policy records** that are either materially more specific or fill an actual runtime gap.

## Beta boundaries

- Lived-world records use `[DNA]`: they influence Mary as shared character DNA, not AI-lived memories.
- Interaction-policy records use `[AI]`, with `[NEG]` only where the record is explicitly a failure mode.
- No `[FC]` event is promoted here because the Alpha pack already contains the strongest fictional behavioral evidence and the current pass is focused on new workbook material.
