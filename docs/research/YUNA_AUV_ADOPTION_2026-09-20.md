# Yuna + AUV/AIRI adoption pass — 2026-09-20

This pass mines mechanisms, not identity architecture. Mary Core remains the
single canonical owner of identity, cognition, memory, relationship, agency and
performance intent.

## Adopted

- **Yuna-style temporal media timeline:** added `mary.perception.media_timeline`.
  Frame/audio observations become timestamped, source-attributed, disposable
  perception evidence. They do not write memory or world truth.
- **Character-experience latency:** added TTFT, time-to-first-audio,
  time-to-first-visible-reaction and total-turn derived metrics. Existing trace
  infrastructure remains canonical.
- **AUV/AIRI request-scoped computer-use grants:** added a bounded contract for
  node execution. Mutating desktop actions require an exact request+turn+node
  grant and verification is requested by default. No shell or GUI executor was
  added.
- **Yuna VRAM scheduling:** already represented by Mary 13.45
  `model_residency`; no duplicate scheduler was created.
- **Yuna procedural embodiment:** already represented by canonical
  PerformancePacket + surface-performance projection + Desktop procedural
  fallback; no second emotion/avatar state owner was created.

## Deliberately not adopted

- Yuna's independent Chroma FACT/UPDATE/FORGET memory owner. Mary already has
  governed canonical memory, temporal evidence and world-model reconciliation.
- An autonomous desktop agent. Execution remains node-owned and permission
  gated.
- A second avatar emotion state. Bodies only render/degrade Mary Core's
  canonical performance packet.
