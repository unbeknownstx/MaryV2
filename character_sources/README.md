# Creator-authored Mary sources

`active/` is automatically discoverable by MaryV2.

`drafts/` is intentionally **not** auto-loaded. The definitive Character Bible remains here while it is being written. When a source is creator-approved, copy/move the approved version into `active/` (or explicitly configure `MARY_CHARACTER_SOURCES`).

Never put API keys, runtime memory databases, or provider output here.
