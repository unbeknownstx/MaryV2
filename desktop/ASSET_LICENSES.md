# MaryV2 Desktop Asset Notes

This private 12.8 first-program pass intentionally avoids bundling third-party commercial/copyrighted UI packs.

## Project-created / procedural assets

The following were created specifically for this MaryV2 package and may be used with the project:

- `public/assets/ui/*.svg`
- `public/assets/backgrounds/*.svg`
- `public/assets/sounds/*.wav`
- generated Mary launcher/application icon assets
- design target images under `desktop/design/`

## Mary character assets

`MaryCosma.vrm`, `maryvrm1.vroid`, and Mary reference art are existing project/user assets. They are kept in the PC Full package and omitted where appropriate from clean source distributions.

## Future optional CC0 packs

Kenney and similar CC0 game-UI/audio packs can be layered in later if desired. They are intentionally not required for first boot so Mary Desktop has no external asset-download dependency.
