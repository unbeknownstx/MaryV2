# MaryV2 12.8 Desktop Asset Notes

The first-program polish pass intentionally avoids relying on remote/CDN runtime assets.

Bundled 12.8 additions include:

- original Mary ecosystem visual target art under `desktop/design/`;
- a project-specific neon Mary sigil SVG;
- a project-specific reusable neon-grid SVG;
- procedurally synthesized local UI sounds for hover, selection, startup, focus completion, idle hum, and idle chime;
- existing Mary reference art and the existing `MaryCosma.vrm` / VRoid source in the PC Full package;
- CSS particle/glow/boot/holographic effects that require no network request.

The synthesized audio and SVG assets were created as part of this MaryV2 build. No third-party sound or UI pack is required to run the shell.

Later art passes may add permissively licensed CC0 assets, but those should be copied into a documented source/attribution manifest rather than silently depending on a web CDN.
