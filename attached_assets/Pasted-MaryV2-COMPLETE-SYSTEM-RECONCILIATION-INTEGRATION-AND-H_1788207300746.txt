We are beginning a comprehensive overhaul of the CURRENT MaryV2 repository.

This is NOT a rewrite.

This is NOT a simplification exercise.

This is NOT permission to flatten Mary into a generic chatbot architecture.

The objective is to make the entire existing MaryV2 system operate as one coherent, deeply connected organism.

You should inspect the ENTIRE repository and improve it comprehensively while preserving valuable complexity, character architecture, persistence, distributed execution, autonomy, memory, and compatibility.

The governing principle is:

Preserve useful complexity. Remove accidental complexity. Strengthen connections. Complete partial systems. Reconcile duplicated concepts. Add missing glue. Harden the whole runtime.
