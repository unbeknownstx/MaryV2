# Unbeknownst — canonical creative workspace

This is the repository-side project home for the Unbeknownst creative pipeline.

```text
book/        manuscript/source/revision material
manga/       scripts, layouts, page/panel production references
animation/   storyboards, animatics, shot plans, generated/animated takes
audio/       voice, dialogue, sound and music production references
assets/      shared visual/reference assets
production/  cross-media plans, manifests, review notes and final assembly metadata
```

Creator-authored drawings, prose and performances remain authoritative creative references. Mary Studio coordinates tools/services around those references; it does not redefine authorship or canon by itself.
