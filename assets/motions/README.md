# Mary Motion Assets

Binary motion files are deliberately **not** stored in Git. `mary.expression.motion_library`
contains semantic motion slots that can resolve to local VRMA/FBX/BVH clips on a capable
presentation node. Keep downloaded/retargeted motion binaries in Mary's local model/asset
storage and record source/license information before use.

The runtime selects motion *after* Mary has already produced a PerformancePacket. Motion
retrieval may realize delivery; it cannot redefine character, emotion, memory, or dialogue.
