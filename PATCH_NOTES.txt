MaryV2 Free-First Adaptive LLM Router Patch
===========================================

Goal
----
Keep Mary's normal LLM usage zero-cost while avoiding the old problem where
Groq hitting a free-tier limit made Mary stop, or Ollama became the slow primary
for every turn.

Default automatic route
-----------------------
Groq -> Gemini -> OpenRouter free -> Ollama

- Missing cloud API keys are skipped automatically.
- OpenAI is NOT selected automatically in free_first mode.
- OpenRouter is forced to openrouter/free unless MARY_OPENROUTER_MODEL is an
  explicit :free model.
- Ollama remains Mary's local/offline final fallback.
- route="private", route="local", or route="offline" forces Ollama only.

Rate-limit behavior
-------------------
When a provider returns a rate-limit error (including HTTP 429), Mary:
1. records that provider failure in provider_attempts,
2. immediately tries the next free provider,
3. locally cools down the rate-limited provider so following turns skip it
   instead of wasting time hitting the same exhausted route again.

Default cooldown: 300 seconds.
If an SDK exposes Retry-After, Mary uses that value instead.

Ollama availability
-------------------
Ollama now checks the local /api/tags endpoint with a short cached health check.
If the Ollama service is stopped, Mary can skip it quickly instead of treating
MARY_OLLAMA_ENABLED=true as proof that the server is actually reachable.

Environment
-----------
The patch includes an updated .env.example. Do NOT overwrite your real .env.
Add these to your existing .env if desired:

MARY_LLM_ROUTING_STRATEGY=free_first
MARY_LLM_FREE_ORDER=groq,gemini,openrouter,ollama
MARY_LLM_RATE_LIMIT_COOLDOWN=300
MARY_GROQ_MODEL=openai/gpt-oss-20b
MARY_GEMINI_MODEL=gemini-2.5-flash
MARY_OPENROUTER_MODEL=openrouter/free

Keep your existing keys; never paste them into chat.

Optional free provider keys:
GROQ_API_KEY=...
GEMINI_API_KEY=...
OPENROUTER_API_KEY=...

Ollama settings can stay as they are. For the current RX 480, 4096 context is a
reasonable normal-turn target if you want to reduce local memory pressure:
MARY_OLLAMA_NUM_CTX=4096

Safe route status check
-----------------------
python -m scripts.check_llm_routes

This prints READY / NOT CONFIGURED and model names only. It does not print API
keys or their values.
