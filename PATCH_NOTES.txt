MaryV2 Multi-Turn Context Lifecycle Patch
==========================================

Purpose
-------
Keep long conversations coherent without retransmitting the entire active
session to every LLM call.

What changed
------------
- Added mary/cognition/context_lifecycle.py.
- DialogueManager still owns the complete in-session history (up to its existing
  max_history); the new lifecycle only selects the bounded LLM-facing window.
- Up to 4 newest completed turns / 8 messages are sent forward.
- The selected recent-history character budget is 5,000 characters.
- Individual old messages are clipped defensively when unusually large.
- Up to 3 short excerpts from older USER turns become ephemeral session anchors.
- Anchors are explicitly NOT durable memory and are not promoted automatically.
- Ordinary conversation remains non-persistent unless it passes through Mary's
  existing explicit memory, relationship, or development paths.
- TurnMindState exposes lifecycle statistics for debugging/telemetry.
- Reasoning sees the bounded recent window and temporary anchors.
- Added Cognition: context_lifecycle diagnostics.
- Added scripts.verify_context_lifecycle (offline; no API calls or memory writes).

Copy/merge
----------
Copy the included mary, scripts, and tests folders over the matching folders in
MaryV2. Do NOT replace your .env or data directory.

Verify
------
python -m pytest tests -q
python -m scripts.run_diagnostics
python -m scripts.verify_context_lifecycle

Expected shape on Windows
-------------------------
Your exact test count may be one higher than the build environment because one
platform-specific test is skipped here. There should be zero failures.
Diagnostics should report 43/43 healthy.

Then test Mary normally
-----------------------
python -m scripts.run_mary

Talk for multiple turns. Context lifecycle metadata is also available on cycle
results as result.metadata['context_lifecycle'].
