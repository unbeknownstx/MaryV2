MaryV2 - Conversation Context + Free Router Efficiency Patch
=============================================================

What this patch changes
-----------------------
1. Updates Gemini's default route from gemini-2.5-flash to gemini-3.6-flash.
   Existing .env files that still explicitly name gemini-2.5-flash are
   transparently migrated by GeminiProvider at runtime.

2. Stops serializing Mary's entire TurnMindState into every ordinary dialogue
   request. The full state remains inside Mary; the LLM receives a compact
   projection containing the character/personality/relationship/emotion/
   continuity details needed to perform the current turn.

3. Removes duplicate creator-profile record metadata (IDs/timestamps) from
   normal LLM prompts while retaining normalized creator facts/preferences/
   goals/communication style and the strict Mary-vs-Unbe identity boundary.

4. Uses bounded completion budgets for dialogue:
      brief    -> 320 tokens
      medium   -> 640 tokens
      detailed -> 1000 tokens
      grounded self-introspection -> 500 tokens
   Local-tool analysis retains its existing 1400-token allowance.

5. Distinguishes Groq HTTP 413/request-too-large failures from genuine rate
   limits. Oversized requests still fall through to the next provider, but no
   longer put Groq into a 5-minute cooldown. Genuine 429/quota failures still
   trigger cooldown.

Measured offline on the lazy-day test prompt
---------------------------------------------
Before:
  system + user prompt chars ~= 25,185
  normal completion reserve   = 2,048 tokens

After:
  system + user prompt chars ~= 11,667
  normal completion reserve   = 640 tokens

This is not a provider-reported token count, but it is a large reduction in
what Mary sends to the model. The live provider metadata on your PC will show
actual prompt_tokens after installation.

Install
-------
Merge/copy this patch into the MaryV2 repo root. Replace files when asked.
Do NOT replace your real .env with .env.example.

Then run:
  python -m pytest tests -q
  python -m scripts.run_diagnostics
  python -m scripts.check_llm_routes

Live test:
  python -c "from dotenv import load_dotenv; load_dotenv(); from mary.core.mary import Mary; m=Mary(); r=m.process('Hey Mary, what would your perfect lazy day look like?'); print(); print('RESPONSE:', r.final_response); print(); print('META:', r.reasoning.metadata)"

Expected routing behavior:
- Groq is attempted first for a normal free-first turn.
- If Groq genuinely rate-limits, it enters cooldown and Mary tries Gemini.
- Gemini should now report gemini-3.6-flash.
- OpenRouter free remains the next fallback.
- Ollama remains the final free/local fallback.
