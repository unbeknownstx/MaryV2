MaryV2 Character Core Pass
==========================

Purpose
-------
Populate the existing MaryV2 architecture with Mary's established core
appearance, personality, values, preferences, social behavior, vulnerabilities,
romance, quirks, activities, speech habits, and personal goals without adding
unrevealed story-canon knowledge.

This patch assumes the previous self-grounding/Ollama patch is already installed.

What changed
------------
1. NEW mary/personality/character_core.py
   - One authored source of truth for Mary's established character core.
   - No Miralonaz secret/canon is added.
   - No favorite color is invented.

2. personality.py
   - Uses Mary's authored trait/style baseline.
   - Adds dimensions such as sociability, wit, romanticism, fieryness,
     artistic sensitivity, and protectiveness while preserving existing tested
     curiosity/creativity/empathy values.

3. character.py
   - Expands character state with social modes, emotional reactions, quirks,
     speech/slang rules, romance, vulnerabilities/soft spots, and private-life
     activities.

4. preferences.py
   - Seeds Mary's authored likes/dislikes as real Preferences state.
   - Core preferences remain separate from later learned preferences.
   - reset() restores authored defaults rather than erasing Mary's established core.

5. values.py
   - Adds Mary's stronger authored priorities: compassion, justice, integrity,
     protection, loyalty, equality, honesty, creativity, care, respect, curiosity,
     growth, and independence.

6. biography.py
   - Adds structured appearance:
       height 5'5"-5'6"
       red hair
       blue eyes
       purple beanie
       blue jacket
       purple shirt
       blue skirt
       knee-high socks
       boots
   - Adds personal goals: homestead, lasting love, travel, and justice.
   - Does NOT add unrevealed story canon.

7. self_model.py / mary.py / mind_state.py
   - Connects the existing Preferences subsystem to live Mary.
   - Adds compact preference state and richer character-expression state to
     TurnMindState.
   - Adds contextual character instructions without forcing catchphrases or
     every trait into every reply.

8. self_introspection.py / orchestrator.py / reasoning.py
   - Grounds questions about appearance, fears, romance, anger/embarrassment,
     strangers vs close friends, distrust, being watched, private activities,
     slang, goals, likes/dislikes, and humor.
   - Rejects provider inventions such as wrong eye color, unrelated fears, or
     unrelated food dislikes when answering Mary-self questions.
   - Keeps these self queries on the compact self-grounded prompt path.

Install
-------
Copy the included mary/ and tests/ folders into the root of your MaryV2 repo and
allow these specific files to replace the existing versions. character_core.py
and the two new test files are new files.

Do NOT replace your .env or data/ folders.

Run after installing
--------------------
python -m pytest tests -q
python -m scripts.run_diagnostics

Then run these real Ollama checks one at a time:

python -c "from dotenv import load_dotenv; load_dotenv(); from mary.core.mary import Mary; m=Mary(); r=m.process('What do you look like?'); print(); print('RESPONSE:', r.final_response); print(); print('REASONING META:', r.reasoning.metadata); print(); print('REFLECTION META:', getattr(r.reflection,'metadata',{}))"

What to look for
----------------
- provider: ollama
- self_grounded: True for direct Mary-self queries
- reflection mode: self_introspection_grounding_reuse
- substantially smaller prompts than the old 5K-token self query path
- answers that sound like Mary while preserving the established facts
