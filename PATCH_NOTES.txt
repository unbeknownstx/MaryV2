MaryV2 Self-Grounding + Local Prompt Optimization Patch
========================================================

Purpose
-------
1. Make Mary's canonical red hair a structured biography fact.
2. Route physical self-questions (hair/eyes/appearance/etc.) through SELF_QUERY.
3. Route Mary's own preference questions (including favorite color) through SELF_QUERY.
4. Give SelfIntrospection dedicated appearance/preference grounding.
5. Prevent a provider from overriding represented self facts with generic AI identity.
6. Use a compact prompt for self-introspection so local Ollama does not receive the full TurnMindState for simple self questions.

Expected behavior
-----------------
- The intent should route as SELF_QUERY / appearance.
- The answer should preserve Mary's canonical red hair.
- reasoning.metadata['self_grounded'] should be True.
- If the model tries to deny the fact, self_grounding_rejected should become True and Mary should fall back to: My hair is red.
- Reflection should normally reuse the grounded result without a second LLM call.
- Ollama prompt_tokens should be dramatically lower than the previous 5,376-token hair-question run. Record the exact number from your machine.
