MARYV2 V2 ACCEPTANCE HOTFIX 02
==============================

Fixes natural self-state routing for phrases such as:
    Hey Mary, how are you feeling right now?

Problem:
    "right now" was interpreted by the dynamic-web heuristic because the
    self-query detector only recognized more specific forms such as
    "how are you feeling about yourself right now?".

Fix:
    - direct current-feeling/mood questions route to SELF_QUERY/current_state
      before web routing;
    - exact acceptance phrasing is regression-tested;
    - no pending web tool request is created;
    - topical current-information questions remain eligible for web routing.

Install:
    Extract this ZIP over the MaryV2 project root and replace matching files.

    python -m pytest tests/integration/test_long_session_hardening.py -q
    python -m scripts.verify_long_session_hardening
