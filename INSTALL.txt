MaryV2 Natural Relationship Learning - TEST/VERIFIER HOTFIX

Why this hotfix exists
----------------------
The runtime natural-learning integration worked, but two assertions assumed that
RelationshipManager stores every natural preference-shaped sentence under the
"preferences" query. The existing relationship architecture is authoritative:
communication preferences are tracked separately, and "I like ..." may be
classified as an interest.

This hotfix changes NO runtime Mary code.

Replace only:
  tests/relationship/test_natural_relationship_learning.py
  scripts/verify_natural_relationship_learning.py

Then run:
  python -m compileall -q mary scripts tests
  python -m pytest tests -q --durations=10
  python -m scripts.run_diagnostics
  python -m scripts.verify_natural_relationship_learning

Expected full-suite target from the current baseline:
  385 passed, 1 skipped

Do not replace mary/core/mary.py or mary/relationship/natural_learning.py again.
