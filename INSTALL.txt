Design boundary:
    evidence -> candidate -> eligible -> explicit promotion -> developed self

Rules:
- One observation is never enough.
- Default eligibility requires 3 observations.
- Mean confidence >= 0.70.
- Directional consistency >= 0.75.
- Mean magnitude >= 0.50.
- Model/LLM/situational/imagination output cannot count as evidence.
- Duplicate evidence_id values do not increase observation count.
- Eligibility never auto-mutates Mary's Preferences.
- Canonical authored preferences cannot be overwritten through this path.
- Tentative evidence persists separately in preference_promotion.json.
- Promoted preferences persist through developed_self.json.
- Plain Mary() keeps both persistence systems unconfigured.
