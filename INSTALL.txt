MARYV2 FINAL CONSOLIDATION OVERLAY

This source overlay is designed to be copied onto the existing MaryV2 project.
It intentionally does NOT contain or replace the user's .env, data/, persistent
character state, API keys, desktop VRM assets, node_modules, or built dist assets.

1. Make a backup / GitHub Desktop commit of the current working MaryV2 folder.
2. Extract/copy the consolidation overlay into the MaryV2 root and replace files.
3. Do NOT delete .env or data/.
4. With .venv active, run:

   python -m pip install -r requirements.txt
   python -m pytest tests -q
   python -m scripts.run_diagnostics
   python -m scripts.run_release_verification --offline

5. Rebuild the desktop on Windows:

   cd desktop
   npm ci
   npm run build
   cd ..
   python -m scripts.run_desktop

6. Terminal runtime:

   python -m scripts.run_mary

   Use /state and /resources to inspect display-safe runtime state.

7. Only after the source/runtime hard tests are green, build the standalone app:

   powershell -ExecutionPolicy Bypass -File scripts\build_windows.ps1

No live OpenAI call is required by this installation or hard-test sequence.
